# STRUKTUR WEBSITE YUKKE TEMBI HOMESTAY

Website ini dibuat sebagai template statis HTML/CSS/JS dan responsif untuk PC, tablet, dan HP.

## 1. GAMBAR YANG HARUS ANDA SIAPKAN

Masukkan gambar ke folder:

assets/images/

Nama file yang digunakan website:

1. logo.png
   - Logo homestay transparan/PNG
   - Rekomendasi: 500 x 500 px

2. hero.jpg
   - Foto utama/foto depan homestay
   - Rekomendasi: 1920 x 1000 px atau lebih
   - Dipakai sebagai background halaman paling atas

3. about.jpg
   - Foto area/halaman homestay
   - Rekomendasi: 1200 x 800 px

4. rooms-bg.jpg
   - Foto background bagian "Pilihan Kamar"
   - Rekomendasi: 1920 x 900 px

5. room-travel-queen.jpg
   - Foto kamar Travel Queen
   - Rekomendasi: 1000 x 700 px

6. room-standard-queen.jpg
   - Foto kamar Standard Queen
   - Rekomendasi: 1000 x 700 px

7. room-deluxe-queen.jpg
   - Foto kamar Deluxe Queen
   - Rekomendasi: 1000 x 700 px

8. room-cottage.jpg
   - Foto Cottage
   - Rekomendasi: 1000 x 700 px

9. room-villa.jpg
   - Foto Villa
   - Rekomendasi: 1000 x 700 px

10. gallery-1.jpg sampai gallery-6.jpg
   - Foto galeri homestay
   - Rekomendasi: minimal 1000 x 700 px

11. contact.jpg
   - Foto tambahan untuk bagian kontak
   - Rekomendasi: 1200 x 900 px

## 2. KALAU GAMBAR MAU DARI LINK INTERNET

Di index.html, contoh:

<img src="assets/images/hero.jpg">

Bisa diganti menjadi:

<img src="https://domain-anda.com/foto/hero.jpg">

Begitu juga semua gambar lainnya.

## 3. YANG WAJIB DIGANTI

- Nama "Yukke Tembi Homestay"
- Logo
- Semua foto
- Nomor WhatsApp di index.html dan js/script.js
- Email
- Teks deskripsi
- Nama kamar
- Kapasitas kamar
- Link sosial media jika ingin ditambahkan
